First stable release of Draft0 — zero-config presets for modern TypeScript projects.

**What's included**

- `@draft0/tsconfig`: TypeScript config presets (Node 22+, library, app).
- `@draft0/oxlint`: Oxlint presets with sensible strictness defaults.
- `@draft0/oxfmt`: Oxfmt presets for consistent formatting.
- `@draft0/tsdown`: tsdown-based build preset with `attw` and `publint` checks.
